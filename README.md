# WeFix / NextFix Pro — Smart Device & Gadget Repair Theme

Exact 1:1 Light Mode reproduction of the ThemeForest WeFix WordPress Theme (`https://wdtwefix.wpengine.com`), engineered with Next.js App Router, TypeScript, Tailwind CSS, Lucide icons, and Canvas Confetti.

## 🎨 Theme & Visual Architecture (100% Light Mode)

- **Pure Light Mode Base:** Clean crisp white background (`#FFFFFF`), subtle secondary section contrast (`#F6F6F6`), charcoal text (`#1F1F1F` / `#636363`), and signature WeFix coral-orange accent (`#EF644C`).
- **Typography:** Space Grotesk / Plus Jakarta Sans for headings with signature character spacing (`wdt-spaced-heading`), and Manrope / Inter for crisp body readability.
- **Strictly 360px+ Mobile Responsive:** Tested across minimum mobile width (360px) up to 4K desktop with zero horizontal scroll overflow.
