# NextFix Pro™ — Certified Device, Phone & Computer Repair Lab

NextFix Pro is a high-converting, production-ready web application built for the **Device, Phone & Computer Repair Shop / Tech Services** niche. Engineered with Next.js App Router, TypeScript, Tailwind CSS, Lucide icons, and Framer Motion.

## ⚡ Core Features & Architectural Highlights

1. **Top Emergency Bar & Live Marquee Ticker:**
   - Real-time animated ticker with dispatch notice: `"⚡ Walk-ins Welcome • Average Screen Repair Time: 28 Minutes • Lifetime Parts Warranty • 100% Data Privacy Guaranteed"`.
   - Store open status with dynamic pulse badge (`● Open Now until 8:00 PM`), direct hotline `(555) 839-3490`, and quick address peek.

2. **High-Conversion Hero Section:**
   - Bold value hook: *"Cracked Screen or Dead Battery? Fixed in Under 45 Minutes with Certified OEM Parts."*
   - Dual CTAs: Instant Price Estimator + Direct Urgent Phone Hotline.
   - Dynamic Trust Badges strip: Lifetime Workmanship Warranty, No Fix = No Fee Guarantee, 100% Data Privacy & Security, 4.9/5 Star Rating across 2,400+ reviews.
   - Live lab workstation visualization with telemetry floating queue badges.

3. **Interactive Multi-Step Repair Price Estimator Widget (CRO Engine):**
   - **Step 1 (Select Device):** iPhone, Samsung Galaxy, Google Pixel, MacBook & Laptop, iPad & Tablet, Gaming Consoles.
   - **Step 2 (Select Model):** Dynamic model list (e.g. iPhone 16 Pro Max, Galaxy S24 Ultra, MacBook Pro M3, PS5 Slim, etc.).
   - **Step 3 (Select Issue):** Screen replacement, battery renewal, liquid damage decontamination, port replacement, micro-soldering, back glass laser separation, camera array.
   - **Step 4 (Instant Cost & Turnaround):** Real-time calculated quote, OEM Grade vs Premium Aftermarket tier selector, warranty guarantee, and 1-click booking integration.

4. **Service Categories & Pricing Breakdown:**
   - Interactive category tabs (Smartphones, Mac & Laptops, Micro-soldering, Consoles, All).
   - Clean card grid showcasing starting prices, turnaround windows (20–40 Mins, Same-Day), warranty tags, and direct booking triggers.

5. **Interactive Before & After Repair Visualizer:**
   - Draggable horizontal split-screen slider with touch and mouse drag handling.
   - Real repair showcase tabs (iPhone 15 Pro, MacBook Pro M3 Max, PS5 Console).
   - Technical diagnostic specifications and verification checklist.

6. **4-Step Precision Cleanroom Workflow:**
   - Step 1: Drop-off or Express Mail-in (Free insured FedEx prepaid mailer).
   - Step 2: Complimentary Multi-Point Hardware Diagnostic ($0 bench assessment fee).
   - Step 3: Precision Repair in ISO Class 7 Cleanroom with ESD protection and stereomicroscopes.
   - Step 4: 30-Point Quality Control & Lifetime Warranty Certificate handover.

7. **Authentic Customer Reviews & Google 5-Star Social Proof:**
   - Overall rating score card (4.9 / 5.0 from 2,418+ verified reviews).
   - Verified customer review cards with device badges, repair tags, turnaround times, and verified buyer markers. Filterable by device.

8. **Interactive Location, Hours & Walk-In Directions:**
   - Flagship lab address in San Francisco with free reserved customer parking details.
   - Operating hours schedule with real-time open status.
   - High-tech simulated dark-mode map with driving, transit, and walking route selectors.
   - Express Mail-In Repair Kit instructions tab.

9. **Live Repair Status Tracker Modal:**
   - Input ticket numbers (or try demo tickets: `NFX-8492`, `NFX-2041`, `NFX-9104`).
   - Shows live multi-stage hardware progress, diagnostic health score (100%), technician notes, verified replacement parts, and contactless smart locker pickup codes.

10. **Interactive Diagnostic Booking Modal:**
    - Full scheduling flow with date picker, arrival windows, customer contact info, and Zero-Touch Data privacy options.
    - Post-booking celebration screen with confetti animation and printable/copyable confirmation reference ticket.

11. **Mobile Bottom Sticky Dock:**
    - Fixed bottom conversion dock on mobile devices with `[ 📞 Call Shop ]`, `[ ⚡ Estimate ]`, and `[ 📍 Directions ]`.

12. **High-Resolution Photography Engine:**
    - 100% royalty-free, high-resolution photography strictly from Unsplash (cleanroom electronics labs, micro-soldering under microscope, ESD technicians, motherboard circuits).

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Animations & Effects:** Framer Motion, Canvas Confetti

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### 3. Production Build
```bash
npm run build
npm start
```
